# Built-in font

JetBrains Mono 2.304 (Regular, Bold, Italic, Bold Italic), the static TTFs
from <https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304>,
unmodified. Seraphim embeds them in its binary and uses them when no
`font.family` is configured, so a window can open without scanning the
system fonts first.
